## Part A · 汇编指令序列表格填空（每题 10 分，共 20 分）
*Complete the instruction sequence to form a working program. The pre-filled lines are marked 「给定」.*

### A1. 求数组最大值（10 分）
补全指令序列：找出数组 `data` 中**最大**的元素，存入 C++ 变量 `maxVal`。程序运行结束后 `maxVal == 11`。

```cpp
#define N 5
int data[N] = { 8, 3, 11, 7, 5 };
int maxVal;
_asm {
    lea   esi, data          ; Line 1 — 给定
    mov   eax, [esi]         ; Line 2 — 给定
    _______________________  ; Line 3
next:
    add   esi, 4             ; Line 4 — 给定
    _______________________  ; Line 5
    _______________________  ; Line 6
    _______________________  ; Line 7
skip:
    _______________________  ; Line 8
    mov   maxVal, eax        ; Line 9 — 给定
}
```

### A2. 统计负数个数（10 分）
补全指令序列：统计数组 `data` 中**负数**（严格小于 0）的个数，存入变量 `negCount`。程序运行结束后 `negCount == 3`。

```cpp
#define N 6
int data[N] = { -2, 5, -9, 3, -1, 8 };
int negCount;
_asm {
    lea   esi, data          ; Line 1 — 给定
    _______________________  ; Line 2
    mov   ecx, N             ; Line 3 — 给定
next:
    _______________________  ; Line 4
    _______________________  ; Line 5
    _______________________  ; Line 6
    _______________________  ; Line 7
skip:
    _______________________  ; Line 8
    _______________________  ; Line 9
    mov   negCount, ebx      ; Line 10 — 给定
}
```

## Part B · 代码补全填空（每题 6 分，共 30 分）
*Drag the correct instruction into each blank ①②③…，每个空填一条指令（或一个参数）。*

### B1. 求绝对值
```cpp
int value = -15, result;
_asm {
    mov   eax, value
    ______________          ; ① 让标志位反映 eax 的符号
    ______________          ; ② 若结果非负则跳过取负
    ______________          ; ③ 取负
positive:
    mov   result, eax       ; result == 15
}
```

### B2. 有符号除法
```cpp
int dividend = 20, divisor = 3, quot, rem;
_asm {
    mov   eax, dividend
    ______________          ; ① 为有符号除法准备 EDX
    mov   ecx, divisor
    ______________          ; ② 有符号除法
    mov   quot, eax         ; quot == 6
    mov   rem,  edx         ; rem  == 2
}
```

### B3. 调用 printf
```cpp
char msg[] = "Result: %d\n";
int value = 5;
_asm {
    mov   eax, value
    ______________          ; ① 压入整数实参
    lea   eax, msg
    ______________          ; ② 压入格式串地址
    ______________          ; ③ 调用 C 库函数
    ______________          ; ④ 清理两个实参（共 8 字节）
}
```

### B4. 变址寻址的比例因子
```cpp
int arr[5] = { 2, 4, 6, 8, 10 };
int fourth;
_asm {
    lea   esi, arr
    mov   ecx, 3
    mov   eax, [esi + ecx * ___]   ; ① 访问 int 数组所需的比例因子
    mov   fourth, eax              ; fourth == 8
}
```

### B5. 嵌套循环中的 ECX 保存
```cpp
_asm {
    mov   ecx, 3
outer:
    ______________          ; ① 保存外层计数器
    mov   ecx, 5
inner:
    loop  inner
    ______________          ; ② 恢复外层计数器
    loop  outer
}
```
