## 1. 三大组成 Three components

计算机系统 = 硬件 + 软件 + 数据，三者缺一不可：

| 组成 | 是什么 | 特点 |
|---|---|---|
| **Hardware 硬件** | 可触摸的物理机器：处理器、内存、存储、外设 | 速度快，但只会执行**极简单**的操作 |
| **Software 软件** | 指挥硬件的指令：**系统软件**（OS、驱动、编译器）+ **应用软件**（游戏、Office） | 把简单操作组合成有用的工作 |
| **Data 数据** | 被处理的对象 | 与程序一样以二进制存放；**本身无意义，直到被解释** |

> 判断句：Remove any one of the three and there is no system — only parts.

## 2. 系统的层次 Hierarchy of systems

- 计算机是**分层构建**的：每一层**隐藏下一层的复杂性**，向上层提供更简单的接口（interface）。
- 例：应用 → 编程语言 → 操作系统 → 指令集架构（ISA）→ 微架构 → 数字逻辑 → 晶体管。每层只关心相邻层。
- 考点形式：「哪句话描述层次化思想？」→ 关键词 **hide complexity / simpler interface**。

## 3. 输入-处理-输出模型 Input-Process-Output model

- Input data → **Process**（在存储程序控制下）→ Output data；
- **同一台机器能做不同的事，靠的是换程序**——这就是通用计算机（general-purpose machine）的本质；
- 这是一个高度概念化的模型：方便推理，刻意不谈具体实现。

## 4. 机器指令 Machine instructions

### 4.1 一条指令的三种视图（会互相转换）
| 视图 | 例子 |
|---|---|
| 二进制（机器码） | `1000 1001 1101 1000` |
| 十六进制（速记） | `89 D8` |
| 汇编（人可读） | `MOV EAX, EBX` |

- 转换规则：**4 位二进制 = 1 位十六进制**（`1001=9`、`1000=8`、`1101=D`）；
- CPU 只看二进制；汇编只是给二进制模式起的名字。

### 4.2 指令集的特性
- 每个 CPU 有自己的指令集，约 **100–200 条**指令；对特定机器**固定、不能扩展**；
- 不同 CPU 的指令集大致相似，但**没有统一标准**。

### 4.3 指令四类（类别 + 例子，必背）
| 类别 | 作用 | 例子 |
|---|---|---|
| I/O | 与外部设备交换数据 | `IN`、`OUT` |
| 数据传输与运算 | 移动/计算数据 | `MOV`、`ADD`、`MUL`、`AND`、`OR` |
| 程序控制转移 | 改变执行顺序 | `JMP`、`JC`、`CALL`、`RET` |
| 机器控制 | 控制机器状态 | `HLT`（停机）、`INT`（中断）、`NOP` |

## 5. 冯·诺依曼模型 von Neumann model（1945 EDVAC 报告）⭐

### 5.1 五个要点
| 要点 | 解释 |
|---|---|
| ① 程序 = 指令列表 | 一步一步指挥机器完成任务 |
| ② **程序与数据共享同一内存** | 都以二进制存放、不加区分 |
| ③ 内存可改写 | 换任务只需换内存内容 → **通用性**的来源 |
| ④ 处理器是主动部分 | 按顺序取指执行（跳转会改变顺序） |
| ⑤ 存在**瓶颈 bottleneck** | 指令和数据共用同一条通路 |

### 5.2 瓶颈详解（高频考点）
- 为什么是瓶颈：CPU 取指令、取数据都要经过**同一条通路**（总线），CPU 大部分时间在**等内存**；
- 缓解手段：**缓存（cache）、更宽的总线、预取（prefetch）**。
- 助记：冯·诺依曼 = 「一机器、一内存、一条通路」——通用性换来的代价。

## 6. 哈佛架构 Harvard architecture

- **程序与数据物理分离**、各有各的总线 → 取指与取数**可以同时进行**（吞吐更高）；
- 典型：DSP（数字信号处理器）、PIC/AVR 微控制器；
- **现代处理器 = modified Harvard**：主存统一，但**指令缓存与数据缓存分开**——兼顾两种架构的优点。

| | 冯·诺依曼 | 哈佛 |
|---|---|---|
| 程序/数据存放 | 同一内存 | 分开的内存 |
| 总线 | 共用一条 | 各有一条 |
| 优点 | 简单、通用、内存利用率高 | 取指取数并行、快 |
| 缺点 | 瓶颈 | 复杂、内存利用率低 |

## 7. 硬件与软件的接口 Compatibility

- 硬件与软件通过**接口**协作；指令集就是硬件与软件之间的"合同"；
- **向后兼容**：1978 年为 Intel 8086 编译的程序，今天仍能在 x86 处理器上运行（Intel 系列兼容性好）。

## 8. VHDL 与数字逻辑设计（了解）

- **VHDL**（硬件描述语言）可描述硬件设计；
- 好处：设计可以**先仿真、后制造**——在错误还便宜的时候发现错误；
- 描述自动输入综合（synthesis）与布局（layout）工具，生成最终电路。

## 9. 计算趋势 Trends（了解）

- **摩尔定律 Moore's Law**：约每两年晶体管数量翻倍，支撑了五十年的指数增长；
- 现在**时钟频率趋于停滞**（约 5 GHz），性能增长转向**并行**（多核）；
- 未来趋势（candidates）：多种技术并行发展。
