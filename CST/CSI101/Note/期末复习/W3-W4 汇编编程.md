## 1. 环境与基本规则

- VS2022 新建 **Console App (C++)**；工具栏 **Solution Platforms 必须改 x86**（x64 下 `_asm` 报 **C4235**）；顶部 `#include <cstdio>`；**Ctrl+F5** 运行。
- **数据全部由 C++ 声明**：`_asm` 块内**不能**定义 DB/DW/DD；汇编里直接写 C++ 变量名/函数名/标签。
- 注释 `;` 或 `//`；指令不区分大小写，但**变量名区分大小写**。
- **Intel 语法**：`指令 目的, 来源`，数据**从右往左**流（`mov eax, ebx` = eax ← ebx）。

## 2. 八个通用寄存器（必背）⭐

| 寄存器 | 角色 | 使用规则 |
|---|---|---|
| **EAX** | 累加器：运算主力、**函数返回值** | ✅ 随便用 |
| **EBX** | 基址/通用 | ⚠️ 用前 push、用完 pop |
| **ECX** | 计数器（`loop` 自动使用） | ✅ 随便用 |
| **EDX** | 乘除扩展、**除法余数** | ✅ 随便用 |
| **ESI / EDI** | 源/目的索引（数组遍历） | ⚠️ 用前 push、用完 pop |
| **EBP** | 栈帧基址 | ❌ 绝不能动 |
| **ESP** | 栈顶指针 | ❌ 绝不能动 |

**拆分**：32 位 EAX → 低 16 位 **AX** → **AH（高 8 位）/ AL（低 8 位）**。⚠️ 写 AL 只改低字节——大小混用是经典 bug。

## 3. EFLAGS 状态标志（必考）⭐

| 标志 | 何时置 1 | 配合的跳转 |
|---|---|---|
| **ZF 零标志** | 运算结果 = 0 | JE / JNE（JZ / JNZ） |
| **SF 符号标志** | 结果最高位 = 1（有符号负数） | JS / JNS |
| **CF 进位标志** | 无符号结果放不下（超出 MSB 的进位/借位） | JC / JNC；JA/JB |
| **OF 溢出标志** | 有符号结果放不下（同号相加得异号） | JO / JNO；JG/JL |

> `cmp a, b` 内部算 **a − b** 只留标志：a=b → ZF=1（je）；a>b（有符号）→ JG；a>b（无符号）→ JA。**第一个操作数"减"第二个**——比较方向别记反。

## 4. 操作数与寻址方式 ⭐

- 操作数三类：**寄存器 / 立即数 / 内存**；⚠️ **两个操作数不能都是内存**。
- 大小：BYTE(8) / WORD(16) / DWORD(32)；歧义时显式写 `DWORD PTR [esi]`。

| 方式 | 写法 | 含义 |
|---|---|---|
| 立即数 | `mov eax, 42` | 直接放 42 |
| 寄存器 | `mov eax, ebx` | 复制寄存器 |
| 直接 | `mov eax, total` | 取变量 total 的**内容** |
| 寄存器间接 | `mov eax, [esi]` | 取 esi 所指地址处的内容 |
| 基址+位移 | `mov eax, [esi+8]` | 取 [esi+8] 处内容 |
| 变址比例 | `mov eax, [esi+ecx*4]` | 数组第 ecx 个 int（比例 1/2/4/8） |
| 完整 | `mov eax, [esi+ecx*4+8]` | 基址 + 索引×比例 + 位移 |

> **LEA vs MOV（高频）**：`lea ebx, myarray` 取**地址**；`mov eax, myarray` 取**内容**。printf/scanf_s 要地址 → 用 lea。
> 例：myarray 首地址 0x1234、myarray[0]=2：`mov eax, myarray` → eax=2；`lea ebx, myarray` → ebx=0x1234。

## 5. 栈 The stack ⭐

**盘子比喻**：栈像一摞盘子——只能从**最顶上**放（push）、从**最顶上**拿（pop），中间和底下的碰不到。**ESP 永远指向栈顶**（最顶上的那个数据）。

**向低地址生长**：新数据放在**更小**的地址上（CPU 的约定，记住方向即可）。push 一次 ESP −4，pop 一次 ESP +4。

```
高地址  0x1000  ─┐
        0x0FFC  │ ← 栈顶（ESP 指向这，新数据放这）
        0x0FF8  │
低地址  0x0000  ─┘
```

**PUSH / POP 各两步**：
- `push eax`：① `ESP ← ESP−4`（腾出 4 字节空位）→ ② `[ESP] ← eax`（值写进空位）。
- `pop ebx`：① `ebx ← [ESP]`（读走栈顶值）→ ② `ESP ← ESP+4`（顶上移；旧数据残留但作废）。
- `[ESP]` = ESP 这个地址处的**内容**。⚠️ 十六进制借位：0x1000 − 4 = **0x0FFC**（就像十进制 1000 − 4 = 996）。

**走查**（ESP 初始 0x1000）：

| 步骤 | ESP | 0x0FFC 处的内容 |
|---|---|---|
| 初始 | 0x1000 | （空） |
| `push eax` | **0x0FFC** | eax 的值 |
| `pop ebx` | **0x1000** | ebx 取走该值；残留作废 |

- 32 位寄存器 = 4 字节 → 栈顶一次挪 4；"2 个参数 = 8 字节"即 2×4（见第 8.2 节）。
- **CALL** = push 返回地址 + 跳转；**RET** = pop 返回地址 + 跳回。返回地址就是第 8 节栈帧里的 `[ebp+4]`。
- **考试贯穿点**：EBX/ESI/EDI 用前 push、用完 pop（第 8.2 节）；参数靠 push 压栈、调用方 `add esp, 4×n` 清栈；忘 pop → 栈不平衡 → 块外崩溃（第 11 节）。

## 6. 指令全集（每条要会写、会说作用）⭐

### 6.1 数据移动
- `mov` 复制；`xchg a,b` 交换两个操作数；
- `push/pop`；`lea` 取地址；
- `movzx`（零扩展，无符号转大）、`movsx`（符号扩展，有符号转大）。

### 6.2 算术
- `add` / `sub`（结果存第一个操作数）；`inc`（+1，**不改 CF**）/ `dec`；`neg`（取负）；
- `imul` 有符号乘；
- **除法三件套（必背）**：
```asm
mov eax, dividend    ; 被除数进 eax
cdq                  ; 有符号：eax 符号扩展到 edx（无符号则 xor edx, edx）
idiv divisor         ; edx:eax ÷ 除数 → 商在 eax、余数在 edx
```
> 例：17 ÷ 3 ⇒ eax=5、edx=2。`cdq`（Convert Doubleword to Quadword）把 EAX 符号位填满 EDX；不写它，EDX 的垃圾值会让商错得离谱。**有符号 cdq、无符号 xor edx,edx**，别配错。

### 6.3 逻辑与移位
- `and/or/xor/not`；**`xor eax, eax` = 清零惯用法**（比 mov eax,0 短）；
- `test a,b` = 与运算只留标志：测位 `test edx,1` + `jnz`（判奇偶）；测零 `test eax,eax` + `jz`；
- `shl`（左移=×2）、`shr`（逻辑右移补 0）、`sar`（算术右移复制符号位）、`rol/ror` 循环移位。
> **SHR vs SAR 经典题**：−32 = 0xFFFFFFE0。`shr 2` → 0x3FFFFFF8 = 1073741816（错！）；`sar 2` → 0xFFFFFFF8 = −8（对，÷4）。**负数右移必须 SAR**。

### 6.4 跳转家族完整表（必背）
| 判断    | 有符号（int）                         | 无符号 |
| ----- | -------------------------------- | --- |
| 大于    | JG                               | JA  |
| 大于等于  | JGE                              | JAE |
| 小于    | JL                               | JB  |
| 小于等于  | JLE                              | JBE |
| 相等/不等 | JE / JNE（共用）                     |     |
| 其它    | JMP；JS/JNS（SF）；JC/JNC（CF）；JO（OF） |     |
|       |                                  |     |

## 7. 控制流模板（三个都要能默写）⭐

**① if-else**
```asm
    mov   eax, a
    cmp   eax, b
    jg    bigger          ; a > b ?
    ; ...else 分支...
    jmp   done
bigger:
    ; ...then 分支...
done:                     ; 标签后必须跟指令！
```
**② 计数循环（LOOP）**
```asm
    mov   ecx, 10
again:
    ; ...循环体...
    loop  again           ; = dec ecx + jnz again
```
**③ 条件循环（测顶部）**
```asm
    mov   esi, 0
check:
    cmp   esi, limit
    jge   finish
    inc   esi
    jmp   check
finish:
```
> **LOOP 两个陷阱**：① ECX=0 进入 → 先 dec 变 4,294,967,295 → 循环约 42 亿次（进入前测零）；② LOOP 是短跳转（128 字节内），循环体太长编译报错。
> **LOOP 与 INC 都不改标志**：所以 `shr`（留 CF）后可安全接 `jnc`、`inc`、`loop`。
> **嵌套循环**：内外层争 ECX → 内层前 `push ecx`、内层后 `pop ecx`。

## 8. 函数与调用约定 Calling conventions ⭐（必考大题）

### 8.1 三个约定
| 约定 | 谁清栈 | 特点 |
|---|---|---|
| **__cdecl** | **调用方**（`add esp, 4×n`） | C++ 默认；printf 必须用（参数个数可变） |
| __stdcall | 被调方（`ret n`） | Windows API |
| __fastcall | 调用方 | 前两个参数走 ECX/EDX |

### 8.2 手写调用七步（absDiff(10,3) 逐步走查）
```asm
; --- 调用方 ---
push  3              ; ① 最后一个参数先压
push  10             ; ② 第一个参数后压（右→左！10 更靠近栈顶）
call  absDiff        ; ③ CALL 自动压返回地址并跳转
add   esp, 8         ; ⑤ 返回后调用方清栈：2 参数 = 8 字节
mov   answer, eax    ; ⑥ 结果从 EAX 取回
```
**被调方内部**：
```asm
int absDiff(int a, int b)
{
    int result;
    _asm {
        push  ebx          ; EBX 是"必须保存"寄存器 → 先压
        mov   eax, a       ; a 在 [ebp+8]
        mov   ebx, b       ; b 在 [ebp+12]
        sub   eax, ebx     ; eax = a-b（顺便留下标志！）
        jns   done         ; SF=0 → 已 ≥0，跳过取负
        neg   eax          ; 否则取负
done:
        mov   result, eax  ; 局部变量在 [ebp-4]
        pop   ebx          ; 还原（每条路径都要 pop！）
    }
    return result;         ; 返回值放 EAX
}
```
**栈帧布局（CALL 后）**：
```
[ebp+12]  b（第二个参数）
[ebp+8]   a（第一个参数）
[ebp+4]   返回地址
[ebp]     旧 EBP        ← EBP 指向这里
[ebp-4]   局部变量
```
> 为什么右→左压参：最后压的第一个参数恰好落在 [ebp+8]——被调方按固定偏移找参数。
> 返回值 EAX（64 位用 EDX:EAX）。寄存器保护：EAX/ECX/EDX 随便用；EBX/ESI/EDI 必须还原；EBP/ESP 不能碰。忘还原 → 块外崩溃。

## 9. 调用 C 库函数（printf / scanf_s）⭐

**printf（输出）——传值**：
```asm
mov   eax, value
push  eax              ; ② 第二个参数（值）先压
lea   eax, msg
push  eax              ; ① 第一个参数（格式串地址）后压
call  printf
add   esp, 8           ; 2 参数 × 4 字节
```
**scanf_s（输入）——传地址（lea！）**：
```asm
lea   eax, first       ; scanf_s 要写入变量 → 传地址
push  eax
lea   eax, format
push  eax
call  scanf_s
add   esp, 8
```
> 口诀：printf 传**值**、scanf_s 传**地址**；调用完 `add esp, 4×参数个数`。

## 11. 调试与报错速查

- 快捷键：**F9** 断点 / **F5** 运行 / **F10** 单步跳过 / **F11** 逐指令；**Ctrl+Alt+D** 反汇编、**Ctrl+Alt+G** 寄存器窗口。

| 症状 | 原因 |
|---|---|
| `_asm` not supported（C4235） | 平台还是 x64 → 切 x86 |
| improper operand type | 大小歧义 → 加 DWORD PTR；EAX 与 AL 混用 |
| undeclared identifier | 变量名拼错/不在作用域（_asm 内大小写敏感） |
| 块外崩溃 | 栈不平衡，或 EBX/ESI/EDI/EBP 没还原 |
| 答案符号悄悄错 | 有符号数据用了无符号跳转 / 该用 SAR 用了 SHR |
| 死循环 | LOOP 进入时 ECX=0 |
| 一个结果对、一个乱数 | 指针写漏方括号（`mov ebx, eax` 应为 `mov [ebx], eax`） |
