# W8 · RAM 与内存层次
# RAM and Memory Hierarchy

> 讲义：CSI101-L08 ｜ 返回：[[00 期末复习总览]]

---

## 1. 主存的角色 ⭐

- 冯·诺依曼机器中，**主存是 CPU 唯一的工作区**：CPU 只能操作主存里的数据；
- 输入设备把数据写进主存、输出设备从主存读数据；
- 主存容量决定可运行的最大进程数与可寻址工作空间；
- 两个重要性质：① 主存是**计算机内部**的物理存储；② **CPU 只能处理主存内的数据**（外存数据要先"读"进来）。

## 2. 字节寻址与地址 ⭐

- 最小单位是 bit，但按位访问低效 → 多格并行访问 → **内存按字节寻址（byte-addressable）**：一个地址指向 **8 位**。
- **地址宽度**由 CPU 地址寄存器位数和地址总线位数决定：

| 地址宽度 | 最大内存 |
|---|---|
| 8 位 | 2⁸ = 256 B |
| 16 位 | 2¹⁶ = **64 KB** |
| 32 位（Pentium） | 2³² = **4 GB** |
| 64 位 | 2⁶⁴（天文数字，>170 亿 GB） |

> 例：8 位 CPU 地址 0000 0001 指向 1 字节；32 位 CPU 同一内容要用 32 位地址 0000…0001。

## 3. 端序 Endianness ⭐（必考）

- 多字节整数的两种存放方式。以 **0x12345678** 存进内存为例：

| 地址 | Little endian（x86） | Big endian |
|---|---|---|
| 低地址 | **78**（LSB 在低地址） | 12（MSB 在低地址） |
| ↓ | 56 | 34 |
| ↓ | 34 | 56 |
| 高地址 | 12 | 78 |

- **Little endian**：低字节存低地址；优点：跨不同宽度读写方便（小转大不用移动数据）。
- **Big endian**：高字节存低地址；优点：与人类书写顺序一致、看符号/字符串直观。
- **x86 = little endian**。

## 4. 单位（L08 二进制口径）⭐

- 1 B = 8 bit；**1 KB = 2¹⁰ = 1024 B；1 MB = 1024 KB；1 GB = 1024 MB**（基于 2¹⁰ 的二进制前缀，对应二进制寻址的本质）。
- ⚠️ L02 讲义用十进制口径（TB = 10¹²），两讲口径不同——**按各讲内容记**。

## 5. SRAM vs DRAM ⭐（对比表必背）

| | DRAM | SRAM |
|---|---|---|
| 存储单元 | **电容 + 晶体管**（每 bit 1 个晶体管） | **6 管触发器** |
| 刷新 | **需要**定期刷新（约每 64 ms） | 不需要 |
| 速度 | 慢 | 快 |
| 密度/成本 | 高密度、便宜 | 低密度、贵 |
| 用途 | **主存** | **缓存** |
| 共同点 | **都易失**（断电丢数据） | |

- 性能指标：**延迟 latency**（ns，从请求到第一个数据的时间）与**带宽 bandwidth**（GB/s，总吞吐）。
- 历史上磁带：访问后面数据要扫过前面的；**RAM 随机访问**：无需经过前面的块。

## 6. ROM 家族与固件 ⭐

- **ROM 非易失**（断电保留）：
  - **Mask ROM**：出厂固化，不可改；
  - **EPROM**：紫外线擦除（芯片上石英窗）；
  - **EEPROM / Flash**：电擦除；**Flash 是特殊类型的 EEPROM**。
- **固件 firmware** = "硬件的软件"（帮助硬件设备工作的程序）；
- **BIOS/UEFI 存在 ROM/Flash 里**：因为开机瞬间主存是空的（易失），CPU 需要**硬编码的起始地址**去执行引导程序。

## 7. 内存层次 Memory hierarchy ⭐（四趋势）

越往下（离 CPU 越远）：**容量越大、访问时间越长、被 CPU 访问频率越低、单位成本越低**。

```
寄存器 → L1 → L2 → L3 缓存 → RAM（DRAM 主存）→ 磁盘/SSD（外存）
```
