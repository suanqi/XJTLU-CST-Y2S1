## 一、W10 · 数字电子电路与逻辑门 Digital Circuits & Gates

> 详细展开可看 [[EEE104 复习笔记 Part 1 数制与逻辑门]] 的第 5 节（逻辑门）与第 6 节（晶体管/IC）。

### 1.1 模拟量与数字量
- **模拟量 Analog**：连续取值（温度、声音）；**数字量 Digital**：离散取值（0/1）。
- 数字系统的优势：抗噪、易存储、可编程、结果精确。

### 1.2 逻辑电平与波形
- HIGH（逻辑 1）与 LOW（逻辑 0）；**正逻辑**（高电平=1）与负逻辑（低电平=1）；
- 脉冲：上升沿（leading edge）/ 下降沿（trailing edge）；周期 T、频率 f=1/T、占空比。

### 1.3 七种基本门（真值表 + 表达式 + 符号，必背）

| 门 | 表达式 | 口诀 |
|---|---|---|
| NOT 非门 | $X=\bar A$ | 取反 |
| AND 与门 | $X=AB$ | **全 1 出 1** |
| OR 或门 | $X=A+B$ | **有 1 出 1** |
| NAND 与非门 | $X=\overline{AB}$ | 有 0 出 1（= 负或） |
| NOR 或非门 | $X=\overline{A+B}$ | 全 0 出 1（= 负与） |
| XOR 异或门 | $X=A\bar B+\bar AB=A\oplus B$ | **不同出 1** |
| XNOR 同或门 | $X=\bar A\bar B+AB=A\odot B$ | **相同出 1** |

> 符号约定：输出端**小圆圈（bubble）= 取反**；无圆圈 = 高有效（active-HIGH）。
> **NAND/NOR 是通用门（universal）**：只用 NAND（或只用 NOR）就能搭出 NOT/AND/OR/任意组合电路。

### 1.4 晶体管开关
- BJT/MOSFET 当开关：截止（cutoff）→ 输出接近 VCC（逻辑 1）；饱和（saturation）→ 输出 ≈ 0.2 V（逻辑 0）；
- 一个晶体管 = 反相器；多管组合 = NAND/NOR（CMOS 是主流工艺）。

## 二、W11 · 加法器、锁存器与触发器 Adder, Latch & Flipflop

> 详细展开可看 [[EEE104 复习笔记 Part 3 时序电路]]（锁存器/触发器）与 [[EEE104 复习笔记 Part 2 布尔代数与组合逻辑]] 第 5.1 节（加法器）。

### 2.1 加法器
- **半加器 Half adder**（加两个位）：和 $\Sigma=A\oplus B$；进位 $C_{out}=AB$。
- **全加器 Full adder**（加 A、B 与低位进位 $C_{in}$）：
$$\Sigma=A\oplus B\oplus C_{in},\qquad C_{out}=AB+(A\oplus B)C_{in}$$
- **串行进位加法器 Ripple carry adder**：n 个全加器级联，进位逐位传递。
> 例：1101(13) + 0111(7) 经 4 位加法器 → 10100(20)。

### 2.2 锁存器（电平敏感）
- **SR 锁存器（NOR 版，高有效）**：S=1 置位 Q=1；R=1 复位 Q=0；S=R=0 保持；S=R=1 无效。
- **SR 锁存器（NAND 版，低有效）**：输入为 S̄、R̄；S̄=0 置位；R̄=0 复位；S̄=R̄=1 保持；S̄=R̄=0 无效。
- **门控锁存器**：加使能 EN——EN=0 保持；EN=1 时输入起作用。
- **D 锁存器**：EN=1 时 **Q 跟随 D**（透明）；EN=0 保持。无无效态。

### 2.3 边沿触发器（边沿敏感）
- 只在时钟**有效沿**（上升 ↑ 或下降 ↓）更新；符号上时钟输入有**小三角 ▲**。
- **D 触发器**：$Q^*=D$（时钟沿采样 D）。
- **JK 触发器**（无无效态）：

| J | K | 时钟沿后 Q |
|---|---|---|
| 0 | 0 | 保持 Q₀ |
| 0 | 1 | 0（复位） |
| 1 | 0 | 1（置位） |
| 1 | 1 | **翻转 Q̄₀** |

- **异步预置/清零**（PRE/CLR）：与时钟无关、立即生效；正常同步操作时两者都置无效电平。
- 应用：并行数据存储（一组 D 触发器）、**分频**（JK 翻转模式，每级 ÷2：f/2、f/4…）、**计数**（级联 = 二进制计数器）。

## 三、W12 · 输入输出、操作系统与网络 I/O, OS & Network

### 3.1 输入输出 I/O（必考概念）
- CPU 与外部设备交换数据的三种方式：
| 方式 | 机制 | 特点 |
|---|---|---|
| **轮询 Polling** | CPU 反复查设备"就绪没有" | 简单，但浪费 CPU（忙等） |
| **中断 Interrupt** | 设备就绪时**主动通知** CPU（打断当前执行） | 高效，CPU 不必空转 |
| **DMA**（直接内存访问） | 设备**绕过 CPU** 直接与内存传输数据 | 大批量传输时释放 CPU |

- 为什么外设很慢：键盘按一下 ~几十 ms，CPU 一条指令 ~ns——差了 7 个数量级，所以不能"同步"等。

### 3.2 操作系统 OS（必考概念）
- **OS 是什么**：管理硬件资源、为用户/程序提供服务的系统软件；**内核 kernel** 是 OS 常驻内存的核心。
- **四大职责**：
  1. **进程管理 Process**：创建/调度/终止进程；**调度 scheduler** 决定谁上 CPU（时间片、优先级）；进程 = 运行中的程序 + 自己的内存空间。
  2. **内存管理 Memory**：分配/回收内存；**虚拟内存**（每进程独立地址空间，用磁盘换空间——与 W9 呼应）。
  3. **文件管理 File**：文件的组织（目录/文件系统）、存取权限。
  4. **设备管理/安全 Device & Security**：设备驱动统一接口；用户权限与隔离。
- **系统调用 System call**：用户程序请求 OS 服务的接口（open/read/write/fork…）；**多任务 multitasking** = 快速轮流运行多个进程造成"同时"假象。

### 3.3 网络 Network（必考概念）
- 分类：**LAN**（局域网，校园/家庭）与 **WAN**（广域网，跨城市/国家，如因特网）。
- **分层模型**：
  - **OSI 七层**：物理 → 数据链路 → 网络 → 传输 → 会话 → 表示 → 应用；
  - **TCP/IP 四层**（更实用）：网络接口 → 网际层（IP）→ 传输层（TCP/UDP）→ 应用层（HTTP/DNS/SMTP）。
- **IP 地址**：每台联网设备的逻辑地址（如 192.168.1.10）；**DNS** 把域名翻译成 IP（www.xjtlu.edu.cn → IP）。
- **分组交换 Packet switching**：数据切成**包（packet）**，每个包含地址，独立路由，到目的地重组。
- **协议 Protocol**：通信双方约定的规则。常见：TCP（可靠连接，重传/顺序保证）、UDP（快但不保证）、HTTP（网页）、DNS（域名解析）、SMTP（邮件）。
- **服务器/客户端模型 Client-Server**：客户端发请求，服务器响应（Web 浏览器 ↔ Web 服务器）。
