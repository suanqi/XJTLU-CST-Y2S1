## 1. 无符号整数与 BCD ⭐

### 1.1 无符号范围
- n 位无符号：0 ~ 2ⁿ−1。4 位：0000~1111（0–15）；8 位：0x00~0xFF（0–255）。

### 1.2 BCD（Binary-Coded Decimal，8421 码）
- **每个十进制位单独用 4 位二进制表示**：68₁₀ → `0110 1000`（BCD），而真二进制是 `100 0100`。
- 一字节存 0–99；**ASCII 数字字符的低 4 位 = 它的 BCD**（'5' ASCII = 0110101，BCD = 0101）→ 与字符互转容易（用于键盘、显示等业务应用）。
- 缺点：**比二进制费位**（4 位只用了 10/16 个状态）、运算复杂。
- **BCD 加法 +6 修正**：某 4 位组结果 **≥10 或产生进位**（非法状态）→ 该组 **+0110**。
> 例：45+27：0100 0101 + 0010 0111 = 0110 1100 → 低组 1100（12，非法）→ +0110 = 1 0010 → 本组 0010 进位 1；高组 0100+0010+1 = 0111 ⇒ **0111 0010 = 72** ✓
> 再例：9+1：1001+0001 = 1010（非法）→ +0110 = 1 0000 ⇒ 10 ✓

## 2. 三种负数表示 ⭐（对比表必背）

| | 负数表示 | 零的个数 | 硬件 | 运算特点 |
|---|---|---|---|---|
| **符号-数值 sign-and-magnitude** | 最高位取反（0 正 1 负） | **2 个**（+0/−0） | 加法器 + 减法器 + 比较逻辑 | 同号加、异号减，复杂 |
| **反码 one's complement** | 各位取反 | 2 个 | 只要加法器 | 进位要**绕回（end-around carry）** |
| **补码 two's complement** | 各位取反 **+1** | **1 个** | 只要加法器 | 直接加、丢最终进位——现代标准 |

> **反码循环进位例**（4 位）：(−2)+(+3) = 1101+0011 = 1 0000 → 绕回：0000+1 = 0001（+1）✓
> **符号-数值加法例**：同号加幅值；异号比较幅值、大减小、结果取大数符号（需要"比较 + 减法"两套硬件，所以被淘汰）。

## 3. 补码详解（最重点）⭐

### 3.1 定义与取负
- **负数 = 对应正数取反 +1**：−25 = ~(00011001)+1 = 11100110+1 = **11100111**；
- 再取一次补码回到正数（**补码的补码是原数**）；
- 反码例题（讲义）：10110010 → 反码 01001101 → 补码 01001110。

### 3.2 权重法读值
- **MSB 的权重是负的**：$1011_2 = -8 + 0 + 2 + 1 = -5$。

### 3.3 符号扩展 sign extension
- 左侧补符号位、值不变：正数补 0（011 = 00011 = +3）；负数补 1（110 = 1110 = 11110 = −2）。

### 3.4 范围
- n 位：$-2^{n-1} \sim 2^{n-1}-1$。
- 8 位：**−128 ~ +127**（256 个数）；32 位：−2,147,483,648 ~ 2,147,483,647。

## 4. 补码运算 ⭐

### 4.1 加法：直接加、丢弃最终进位
> +5 + (−5)：00000101 + 11111011 = 1 00000000 → 丢进位 → 00000000 = 0 ✓

### 4.2 减法：加补码
> 9 − 5 = 9 + (−5)：00001001 + 11111011 = 1 00000100 → 4 ✓

### 4.3 溢出判定（必考）
**两操作数符号相同，且结果符号相反 → 溢出**；正+负**永不**溢出。
> 例①：+7 + +1 = 0111 + 0001 = 1000（−8）❌ 溢出（4 位正数最大 +7）
> 例②：−8 + −1 = 1000 + 1111 = 1 0111 → 0111（+7）❌ 溢出

### 4.4 乘法（部分积法 partial products）
1. 按正数算幅值乘积；2. 先置符号位 0；3. 两数异号 → 对结果取补码。
> 例：+83（01010011）× −59（11000101）→ 幅值积 4897，异号 → **−4897**。

### 4.5 除法（反复减）
- 商初始化为 0；用被除数/部分余数减除数：余数为**正** → 商 +1 继续；为 **0** → 商 +1 结束；为**负** → 结束；商符号由被除数与除数符号决定。

## 5. 浮点数与 IEEE 754 ⭐（含编码手算）

### 5.1 为什么需要浮点
- 定点数小数点位置固定 → 表示范围窄（5.07×10³⁰ 与 9.86×10⁻³² 需 207 位）。
- **规格化 normalisation**：去前导零，二进制下小数点前恒为 1（10.1×2⁵ → 1.01×2⁶）。

### 5.2 单精度格式
```
s(1 bit) | exponent(8 bits) | fraction(23 bits)
```
- 指数用 **excess-127**：真实指数 = 存储值 − 127（存储值 1~254 有效；0 和 255 保留）；
- 尾数**隐藏前导 1**（hidden bit）。

### 5.3 编码例题（手算，期末必会）
**例①：−6.5**
> ① 6.5 = 110.1₂ = 1.101 × 2²
> ② s = 1；指数存储值 = 2 + 127 = 129 = 1000 0001
> ③ 尾数：1.101 去隐藏 1 → 101 0000 0000 0000 0000 0000
> ⇒ `1 10000001 10100000000000000000000` = **0xC0D00000**

**例②：0.75**
> ① 0.75 = 0.11₂ = 1.1 × 2⁻¹
> ② s = 0；指数存储值 = −1 + 127 = 126 = 0111 1110
> ③ 尾数：1000 0000 0000 0000 0000 000
> ⇒ `0 01111110 10000000000000000000000` = **0x3F400000**

### 5.4 特殊值（必背）
| 情况 | 值 |
|---|---|
| 指数、尾数全 0 | **零（±0）** |
| 指数全 0 + 尾数非 0 | **非规格化数**（真实指数按 −126，无前导 1） |
| 指数全 1 + 尾数全 0 | **±∞**（∞+任何数=∞；−∞+(−任何数)=−∞） |
| 指数全 1 + 尾数非 0 | **NaN**（√(−1)、∞/∞、∞+(−∞)） |

### 5.5 范围与精度
- float 范围约 **1.2×10⁻³⁸ ~ 3.4×10³⁸**；
- ⚠️ 范围内**不是所有数都能表示**（连部分整数都不行）——对比 int：范围内每个整数都能精确表示。
