## 三、各周核心考点清单 / Weekly Key-Point Checklist

### Week 1 · 基础元件与电路
- [ ] SI 单位制与词头（engineering units，数量级按 3 的倍数）
- [ ] 电荷、电流、电压、功率、能量的定义与单位
- [ ] $i = \dfrac{dq}{dt}$、$q(t)=\int i\,dt' + q(t_0)$
- [ ] 常规电流方向 vs 电子流方向（方向相反）
- [ ] 独立源与受控源（VCVS / VCCS / CCVS / CCCS）
- [ ] 欧姆定律 $v=iR$，电导 $G=1/R$，电阻率 $R=\rho l/A$
- [ ] 功率 $p=vi=v^2/R=i^2R$（电阻恒吸收功率）
- [ ] 被动符号约定（passive sign convention）
- [ ] 开路（$I=0,\ R=\infty$）与短路（$v=0,\ R=0$）

### Week 2 · 电压与电流定律
- [ ] 节点、路径、回路、支路的定义
- [ ] **KCL**：节点电流代数和为零（流入 = 流出）
- [ ] **KVL**：回路电压代数和为零
- [ ] 串联 / 并联的定义（同电流 = 串联；同电压 = 并联）
- [ ] 电阻串联 $R_{eq}=R_1+R_2+\cdots$，并联 $\dfrac{1}{R_{eq}}=\dfrac{1}{R_1}+\dfrac{1}{R_2}+\cdots$
- [ ] **分压** $v_1=\dfrac{R_1}{R_1+R_2}v$；**分流** $i_1=\dfrac{R_2}{R_1+R_2}i$

### Week 3 · 节点与网孔分析
- [ ] 节点分析法（选参考节点，对非参考节点列 KCL）
- [ ] **超节点**（电压源跨两非参考节点）
- [ ] 网孔分析法（对每个网孔列 KVL）
- [ ] **超网孔**（电流源夹两网孔之间）
- [ ] 含受控源的处理（用节点/网孔变量消去受控量）
- [ ] 矩阵法 $Av = B$
- [ ] 节点 vs 网孔如何选择（方程数少者优先）

### Week 4 · 常用电路分析技巧
- [ ] 线性电路与**叠加定理**（电压源→短路，电流源→开路；受控源**不**关断）
- [ ] **电源等效变换**（$R_s=R_p,\ v_s=i_s R_s$）
- [ ] **戴维南定理**（$V_{TH}=v_{oc}$，$R_{TH}=R_{eq}$）
- [ ] **诺顿定理**（$I_N=i_{sc}$，$R_N=R_{eq}$，$V_{TH}=I_N R_N$）
- [ ] 含受控源的等效（$R_{TH}=V_{TH}/I_N$ 或测试源法）
- [ ] **最大功率传输**（$R_L=R_{TH}$，$p_{max}=\dfrac{v_s^2}{4R_s}$）
- [ ] **Δ-Y 变换**公式

### Week 5 · 运算放大器
- [ ] 理想运放两条规则（$i_{in}=0$，$v_d=0$）
- [ ] 反相放大器 $v_{out}=-\dfrac{R_f}{R_1}v_{in}$
- [ ] 同相放大器 $v_{out}=\left(1+\dfrac{R_f}{R_1}\right)v_{in}$
- [ ] 电压跟随器（缓冲器）$v_{out}=v_{in}$
- [ ] 加法器 $v_{out}=-\dfrac{R_f}{R}(v_1+v_2+v_3)$
- [ ] 级联电路（逐级分析）
- [ ] 比较器与施密特触发器（正反馈、迟滞、双阈值）

### Week 6 · 电容与电感
- [ ] 电容 $i=C\dfrac{dv}{dt}$，$q=Cv$，$v(t)=\dfrac{1}{C}\int i\,dt'+v(t_0)$
- [ ] 电感 $v=L\dfrac{di}{dt}$，$i(t)=\dfrac{1}{L}\int v\,dt'+i(t_0)$
- [ ] 电容对直流开路、电压不能突变；电感对直流短路、电流不能突变
- [ ] 储能 $w_C=\dfrac{1}{2}Cv^2$，$w_L=\dfrac{1}{2}Li^2$
- [ ] 串并联等效（电感同电阻；电容相反）
- [ ] 运放积分器与微分器

### Week 7 · RC 与 RL 电路
- [ ] 无源 RC：$v(t)=V_0 e^{-t/RC}$，$\tau=RC$
- [ ] 无源 RL：$i(t)=I_0 e^{-Rt/L}$，$\tau=L/R$
- [ ] 时间常数 $\tau$ 的物理意义（5τ 后 <1%）
- [ ] $v(0^-)=v(0^+)$、$i(0^-)=i(0^+)$
- [ ] 单位阶跃函数 $u(t)$、脉冲表示
- [ ] 有源（driven）RC/RL 完整响应：$x(t)=x(\infty)+[x(0^+)-x(\infty)]e^{-t/\tau}$
- [ ] 四步法（求 $\tau$ → 初值 → 终值 → 代公式）

## 四、总公式速查 / Master Formula Sheet

### 基本量 Basic Quantities
| 量 Quantity | 符号 | 单位 Unit | 关系 |
|---|---|---|---|
| 电荷 Charge | $q,Q$ | C | 电子电荷 $-1.602\times10^{-19}\,\mathrm{C}$ |
| 电流 Current | $i,I$ | A | $i=\dfrac{dq}{dt}$ |
| 电压 Voltage | $v,V$ | V | $1\,\mathrm{V}=1\,\mathrm{J/C}$ |
| 功率 Power | $p,P$ | W | $p=vi$ |
| 能量 Energy | $w,W$ | J | $w=\int p\,dt$ |

### 电阻 / 定律 Resistors & Laws
$$v=iR,\qquad G=\frac{1}{R},\qquad p=vi=\frac{v^2}{R}=i^2R,\qquad R=\rho\frac{l}{A}$$
$$\text{串联 Series: } R_{eq}=R_1+R_2+\cdots \qquad \text{并联 Parallel: } \frac{1}{R_{eq}}=\frac{1}{R_1}+\frac{1}{R_2}+\cdots$$
$$\text{分压: } v_1=\frac{R_1}{R_1+R_2}v \qquad \text{分流: } i_1=\frac{R_2}{R_1+R_2}i$$
$$\text{KCL: }\sum i_{in}=0 \qquad \text{KVL: }\sum v_{loop}=0$$

### 等效电路 Equivalents（Week 4）
$$\text{电源变换: } R_s=R_p,\quad v_s=i_s R_s$$
$$\text{戴维南: } V_{TH}=v_{oc},\ R_{TH}=R_{eq} \qquad \text{诺顿: } I_N=i_{sc},\ R_N=R_{eq},\ V_{TH}=I_N R_N$$
$$\text{最大功率: } R_L=R_{TH},\quad p_{max}=\frac{V_{TH}^2}{4R_{TH}}$$

### 运放 Op Amp（Week 5）
$$v_{out}=A(v_2-v_1),\qquad \text{理想: } A=\infty,\ R_i=\infty,\ R_o=0 \ \Rightarrow\ v_d=0,\ i_{in}=0$$
$$\text{反相 Inverting: } v_{out}=-\frac{R_f}{R_1}v_{in} \qquad \text{同相 Non-inverting: } v_{out}=\left(1+\frac{R_f}{R_1}\right)v_{in}$$
$$\text{加法器 Summing: } v_{out}=-\frac{R_f}{R}(v_1+v_2+v_3)$$

### 储能元件 Energy-Storage Elements（Week 6）
$$i=C\frac{dv}{dt},\quad v=L\frac{di}{dt},\qquad w_C=\frac{1}{2}Cv^2,\quad w_L=\frac{1}{2}Li^2$$

### 一阶电路 First-Order Circuits（Week 7）
$$\text{RC: } v(t)=V_0 e^{-t/RC},\ \tau=RC \qquad \text{RL: } i(t)=I_0 e^{-Rt/L},\ \tau=\frac{L}{R}$$
$$\text{完整响应 Complete: } x(t)=x(\infty)+\big[x(0^+)-x(\infty)\big]e^{-t/\tau}$$

## 五、复习建议 / Study Tips

1. **先刷透基本定律**：KCL、KVL、欧姆定律、分压分流是 Week 3/4 一切方法的基础。
2. **方法选对，事半功倍**：含电流源多用节点法，含电压源多用网孔法（Week 3 末尾的比较页）。
3. **受控源是高频考点**：叠加时受控源不关断；戴维南含受控源用 $R_{TH}=V_{TH}/I_N$ 或测试源法。
4. **Week 7 一阶电路**背熟三步/四步法模板，几乎必考一道完整响应大题。
5. 做完整套模拟卷（[[EEE103 期中模拟试卷（中文版）]] / [[EEE103 期中模拟试卷（英文版）]]）后，把答案上传，我会帮你批改并出复盘练习。
