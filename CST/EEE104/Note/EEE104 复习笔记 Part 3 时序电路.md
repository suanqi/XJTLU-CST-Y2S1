## 1. 锁存器 Latches（Lecture 13）

### 1.1 基本概念
- **锁存器 latch**：存储 1 位的**双稳态**（bistable）电路——两个稳定状态 Q=0 或 Q=1；一个门的输出反馈到另一个门的输入。
- **锁存器 vs 触发器**：锁存器（含门控锁存器）是**电平敏感**；触发器是**边沿触发**。

### 1.2 低有效 S-R 锁存器（NAND 实现）⭐
输入为 $\bar S, \bar R$（active-LOW）：

| S̄ | R̄ | Q | Q̄ | 说明 |
|---|---|---|---|---|
| 1 | 1 | NC | NC | **保持 Hold**（no change） |
| 0 | 1 | 1 | 0 | **置位 SET**（Q=1） |
| 1 | 0 | 0 | 1 | **复位 RESET**（Q=0） |
| 0 | 0 | 1 | 1 | **无效 Invalid**（S̄、R̄ 同时回到 1 时状态不可预测） |

> 原理：S̄ 加负脉冲 → Q=1（SET），脉冲结束后保持（反馈维持）；R̄ 加负脉冲 → Q=0（RESET）。

### 1.3 高有效 S-R 锁存器（NOR 实现）
| S | R | Q | Q̄ |
|---|---|---|---|
| 0 | 0 | NC | NC（保持） |
| 1 | 0 | 1 | 0（SET） |
| 0 | 1 | 0 | 1（RESET） |
| 1 | 1 | 0 | 0（无效） |

> ⚠️ 用真值表前先看**输入极性**（NAND 版低有效、NOR 版高有效，表完全相反）！

### 1.4 波形图例题（必练）
低有效 S-R 锁存器，初始 Q=0，依次施加 (S̄,R̄) = (1,1)→(0,1)→(1,1)→(1,0)→(1,1)：
**Q = 0 → 1 → 1 → 0 → 0**（SET 后保持、RESET 后保持）。

### 1.5 应用：触点抖动消除（Contact-bounce eliminator）
机械开关切换时触点会反复弹跳；锁存器只在**第一次**触碰时改变状态：开关拨向 S 端 → S̄=0 → Q=1；拨向 R 端 → R̄=0 → Q=0；中间悬空（S̄=R̄=1）→ 保持。→ 输出无抖动。

### 1.6 门控锁存器（Gated latch）
- 增加**使能输入 EN**：EN=0 时锁存器**保持**；EN=1 时 S、R 控制输出。
- 内部：$S_{int}=\overline{S\cdot EN}$、$R_{int}=\overline{R\cdot EN}$（NAND 核心，低有效）。
- **门控 S-R**：EN=1 时 S=1→SET、R=1→RESET、S=R=1→无效。
- **门控 D**：S=D、R=D̄（永远互补，无无效态）。EN=1 时 **Q 跟随 D**（透明）；EN=0 时保持。
- 波形例题：门控 D，初始 Q=0，施加 (EN,D)=(0,1)→(1,1)→(1,0)→(0,1)→(1,1)：**Q = 0 → 1 → 0 → 0 → 1**。

## 2. 边沿触发触发器 Edge-Triggered Flip-Flops（Lecture 14）⭐

### 2.1 核心区别
| 器件 | Q 何时更新 | 其余时间 |
|---|---|---|
| 门控 D 锁存器 | EN 为 HIGH 期间（电平敏感） | 保持 |
| 边沿触发 D 触发器 | **时钟有效沿**瞬间 | 保持 |

- 上升沿触发（positive/rising edge）或下降沿触发（negative/falling edge）；符号上时钟输入 C 处有**小三角 ▲**；带小圆圈 = 下降沿触发。

### 2.2 三种边沿触发器真值表（背！）

**S-R（上升沿，↑）**：

| S | R | CLK | Q | 说明 |
|---|---|---|---|---|
| 0 | 0 | × | Q₀ | 保持 |
| 0 | 1 | ↑ | 0 | RESET |
| 1 | 0 | ↑ | 1 | SET |
| 1 | 1 | ↑ | ? | 无效 |

**D（上升沿）**：Q 在时钟沿**跟随 D**（Q*=D）。

**J-K（上升沿，无无效态！）**：

| J | K | CLK | Q | 说明 |
|---|---|---|---|---|
| 0 | 0 | ↑ | Q₀ | 保持 |
| 0 | 1 | ↑ | 0 | RESET |
| 1 | 0 | ↑ | 1 | SET |
| 1 | 1 | ↑ | Q̄₀ | **翻转 Toggle**（Q*=Q̄₀） |

- J-K 与 S-R 的区别：**Q 与 Q̄ 反馈回输入门**，使 J=K=1 时输出翻转而不是进入无效态。

### 2.3 异步预置与清零 Asynchronous Preset/Clear
- **同步输入**（J、K、D、S、R）只在时钟沿起作用；**异步输入**（PRE、CLR）**与时钟无关**，立即生效。
- 低有效：$\overline{PRE}=0$ → 立即置位（Q=1）；$\overline{CLR}=0$ → 立即清零（Q=0）。
- **正常同步操作时 PRE = CLR = 1**；两者同时有效（0,0）禁止。

### 2.4 触发器应用
1. **并行数据存储**：4 个 D 触发器共用 CLK，一个时钟沿同时存入 4 位（如 0110）。
2. **分频 Frequency division**：J=K=1（翻转模式）时每个触发器输出频率为输入的 **1/2**；n 级 → **f/2ⁿ**。
   > 例：CLK = 12 kHz，一级输出 6 kHz，二级（由一级输出驱动）3 kHz。
3. **计数**：负沿触发 J-K（J=K=1）级联 → 2 位二进制序列 00 → 01 → 10 → 11 → 00（QA 为 LSB）。

## 3. 计数器 Counters（Lecture 15–17）

### 3.1 概述与分类
- **计数器** = 一组触发器级联完成计数。
- **异步（行波 ripple）计数器**：每个触发器由**前一级输出**提供时钟 → 逐级翻转，有累积延迟。
- **同步计数器**：所有触发器共用**同一个时钟** → 同时翻转，速度快。

### 3.2 异步二进制计数器
- J=K=1；FF0 由 CLK 触发，FF1 由 Q0 触发，FF2 由 Q1 触发……（负沿触发时为加法计数）。
- n 级 → 模 2ⁿ（n 位二进制计数 0 ~ 2ⁿ−1）。

### 3.3 模数与截断序列
- **模数 modulus**：计数器经历的**唯一状态数**。
- **十进制（decade）计数器**：0000 → 1001（0–9），到 1010 时**部分译码**（只检测 Q1=Q3=1）复位——partial decoding。
- **模 12 计数器**：0000 → 1011，到 1100 复位。
- **累积传播延迟**：异步计数器总延迟 = 各级延迟相加（74LS74A：tPHL 40 ns、tPLH 25 ns）→ 限制最高时钟频率、解码时产生毛刺（glitch）。
- IC：**74LS93A**——使用时要 Q0 接 CLKB；用 NAND 门做译码复位（模 16 / 十进制 / 模 12）。

### 3.4 同步二进制计数器（设计方法 ⭐）
**规则**：看每个触发器在哪些状态需要翻转，写出 J=K 方程：
- Q0 每个时钟都翻转：**J₀ = K₀ = 1**；
- Q1 在 Q0=1 时翻转：**J₁ = K₁ = Q0**；
- Q2 在 Q0=Q1=1 时翻转：**J₂ = K₂ = Q0·Q1**；
- Q3 在 Q0=Q1=Q2=1 时翻转：**J₃ = K₃ = Q0·Q1·Q2**。

**4 位同步十进制计数器（0–9）**：
- J₀ = K₀ = 1；J₁ = K₁ = Q0·Q3̄；J₂ = K₂ = Q0·Q1；J₃ = K₃ = Q0·Q1·Q2 + Q0·Q3。

**IC**：
- **74HC163**：4 位同步二进制计数器——CLR、LOAD 均为**同步**；ENT/ENP 使能；RCO 在计数 15 时为 1。
- **74HC160**：4 位同步十进制——CLR **异步**；RCO 在计数 9 时为 1。
- **74LS190**：可逆十进制（加减）——CTEN 使能；D/U 方向；LOAD 同步预置；MAX/MIN 在 1001/0000 时置 1；RCO 在 9 时为 0。

### 3.5 加减计数器 Up/Down
- 加模式：J₁=K₁=Q0，J₂=K₂=Q0Q1…
- 减模式：Q0 总翻转；Q1 在 110、100、010、000 翻转 → **J₁=K₁=Q0̄**；**J₂=K₂=Q0̄·Q1̄**。

### 3.6 级联计数器 Cascaded Counters
- 级联 = 一个计数器的输出驱动下一个计数器的输入；**总模数 = 各模数之积**。
- 同步 IC 级联：计数器 1 的**终值 TC** 接计数器 2 的**使能 CTEN**——计数器 1 计到 9 时 TC=1，下一时钟沿计数器 2 加 1，然后计数器 1 清零、TC=0。
- 应用：更高模数计数；**分频**（产生更低频且同步的时钟）。
- **截断序列**（实现任意模数）：
  1. 译码终态 → 清零（异步 SR 或同步 SR）；
  2. **装载初值**：如 divide-by-40,000 = 65,535−40,000+1 → 在终值 65,535 时装载 63C0₁₆。

### 3.7 计数器译码 Decoding
- 译码 = 判断某一状态是否出现（如状态 6=110 → 与门接 Q2Q1Q0̄）。
- **异步计数器**：传播延迟产生**过渡状态** → 译码输出**毛刺 glitch**；
- 解决：在过渡结束后再**选通（strobe/gate）**译码输出。

### 3.8 应用：数字钟 Digital Clock
- 秒/分计数器 = **模 60**（÷60）计数器；小时计数器 1–12（到 12 后异步/同步预置回 1）。

## 4. 移位寄存器 Shift Registers（Lecture 18）

### 4.1 定义与类型
- **移位寄存器** = 级联的触发器组，每个时钟沿数据**从一级移到下一级**；每级存 1 位。
- 四种类型（按输入/输出方式）：

| 类型 | 说明 |
|---|---|
| **SISO** | 串行入、串行出（用于时间延迟） |
| **SIPO** | 串行入、并行出（**串→并转换**） |
| **PISO** | 并行入、串行出（**并→串转换**） |
| **PIPO** | 并行入、并行出（快速并行存取） |

### 4.2 数据移动（SISO 例题）
输入 1101，4 个时钟周期后 4 位全部存入：每个时钟沿每位右移一级（注意传播延迟的角色）。

### 4.3 应用
1. **串行 ↔ 并行转换**：外部设备常为串行（如 USB、串口），计算机内部需并行。
2. **时间延迟**：延迟 = 级数 × 时钟周期（由级数和时钟频率控制）。
3. **硬件乘 2 / 除 2**：左移一位 = ×2，右移一位 = ÷2。
   > 例：00001100（12）→ 右移 → 00000110（6）→ 再右移 → 00000011（3）。

### 4.4 常用 IC
- **74HC164**（8 位 SIPO）：A、B 输入都 HIGH → 第一级置位，否则复位；数据逐位移入。
- **74HC165**（8 位 PISO）：**SH/LD 低** → 装载并行数据（G1–G3 打开）；**SH/LD 高** → 移位（G4–G6 打开）；SER 串行数据入、CLK INH 时钟禁止。
- 移位寄存器计数器（如环形计数器 ring counter、约翰逊计数器 Johnson counter）——W13 实验内容，考纲提及。

## 5. 时序电路总复习表

| 器件 | 触发方式 | 关键真值表 | 应用 |
|---|---|---|---|
| S-R 锁存器（NAND，低有效） | 电平 | S̄R̄：11 保持/01 SET/10 RESET/00 无效 | 触点消抖 |
| 门控 D 锁存器 | 电平（EN） | EN=1：Q=D；EN=0：保持 | 数据暂存 |
| D 触发器 | 边沿 | Q* = D | 并行存储、移位寄存器 |
| J-K 触发器 | 边沿 | 00 保持/01 复位/10 置位/11 翻转 | 计数、分频 |
| 异步计数器 | 行波 | 模 2ⁿ，有累积延迟 | 简单计数 |
| 同步计数器 | 同时钟 | J=K 方程按翻转状态推导 | 高速计数 |
| 移位寄存器 | 边沿 | 数据逐级右/左移 | 串并转换、延迟、×2/÷2 |
