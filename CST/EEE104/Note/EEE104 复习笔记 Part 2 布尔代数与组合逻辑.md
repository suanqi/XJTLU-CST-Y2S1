## 1. 布尔代数基础（Lecture 7）

### 1.1 基本概念
- **变量 Variable**：代表逻辑量的符号，取值 0/1。
- **补 Complement**：变量的取反，加横杠 $\bar A$。
- **字面量 Literal**：变量本身或其补（A 和 Ā 是同一变量的两个字面量）。
- **积项 Product term**：字面量之积（如 ABCD），**所有字面量都为 1 时积项才为 1**。
- **和项 Sum term**：字面量之和（如 A+B+C+D），**所有字面量都为 0 时和项才为 0**。
- 布尔加法 = OR（1+1=1！）；布尔乘法 = AND。

### 1.2 定律与 12 条规则（必背）
**定律**：交换律 $A+B=B+A$、$AB=BA$；结合律；分配律 $A(B+C)=AB+AC$。

**12 条规则**：

| # | 规则 | # | 规则 |
|---|---|---|---|
| 1 | $A+0=A$ | 7 | $A\cdot A=A$ |
| 2 | $A+1=1$ | 8 | $A\cdot\bar A=0$ |
| 3 | $A\cdot0=0$ | 9 | $\bar{\bar A}=A$ |
| 4 | $A\cdot1=A$ | 10 | $A+AB=A$（吸收） |
| 5 | $A+A=A$ | 11 | $A+\bar AB=A+B$ |
| 6 | $A+\bar A=1$ | 12 | $(A+B)(A+C)=A+BC$ |

> 规则 10–12 推导：$A+AB=A(1+B)=A$；$A+\bar AB=(A+AB)+\bar AB=A+(A+\bar A)B=A+B$；$(A+B)(A+C)=AA+AC+AB+BC=A+AC+AB+BC=A+BC$。

### 1.3 德摩根定理 DeMorgan's Theorems
$$\overline{XY}=\bar X+\bar Y,\qquad \overline{X+Y}=\bar X\,\bar Y$$

> 口诀：**Break the bar, change the sign**（拆横杠、变符号），对横杠下的整个表达式操作。

> 例：$\overline{(AB+C)(A+BC)}=\overline{AB+C}+\overline{A+BC}=\overline{AB}\,\bar C+\bar A\,\overline{BC}=(A+\bar B)\bar C+\bar A(\bar B+\bar C)$

### 1.4 代数化简例题
> 化简 $AB+A(B+C)+B(B+C)$：
> $=AB+AB+AC+BB+BC=AB+AC+B+BC \xrightarrow{\text{规则10}} AB+AC+B \xrightarrow{\text{规则10}} \mathbf{B+AC}$

> 练习：$R+R(S+T)=R$；$(P+Q)(P+R)+P=P$。

## 2. 组合逻辑电路（Lecture 8）

- **组合逻辑 Combinational logic**：门互连实现某功能；**无存储**，输出只取决于**当前输入**（区别于时序电路）。
- **AND-OR 逻辑**实现 **SOP（积之和）**：$X=AB+CD$。
- **AND-OR-Invert 逻辑**实现 **POS（和之积）**：$\overline{AB+CD}=\overline{AB}\,\overline{CD}=(A+\bar B)(\bar C+\bar D)$。

### 2.1 由表达式画电路
> 例：$X=AB(CD+EF)$。设 $P=CD$、$Q=EF$，则 $X=AB(P+Q)$：两个 AND 生成 P、Q → OR 合成 → 与 AB 相与。三层结构。

### 2.2 通用门：NAND 与 NOR（Universal gates）
- **NAND** 可构成一切：非门（两输入短接）、与门（NAND+反相 = 两个 NAND）、或门（三个 NAND：$\bar{\bar A\,\bar B}=A+B$）、或非门（四个 NAND）。
- **NOR** 同样可构成一切：非门、或门（两个 NOR）、与门（三个 NOR）、与非门（四个 NOR）。
- **等价符号**（画图利器）：NAND = 负或（输入带气泡的 OR）；NOR = 负与（输入带气泡的 AND）。**成对气泡可抵消**，读图时先写每个门输出，再套德摩根。

## 3. 标准形式 SOP 与 POS（Lecture 9）

### 3.1 定义
- **SOP**：积项之和（AND-OR 结构）。例：$AB+BCD$。
- **POS**：和项之积（OR-AND 结构）。例：$(A+B)(B+\bar C+D)$。
- **标准形式 Standard form**：域（domain）中**每个变量在每一项中出现一次**。例：$ABCD+\bar A B\bar C\bar D$（标准 SOP）；$(A+B+C+D)(\bar A+B+\bar C+\bar D)$（标准 POS）。

### 3.2 化成标准形式
- SOP 补变量：乘 $(C+\bar C)=1$。例：$AB+ABCD$ 展开成 5 项标准 SOP。
- POS 补变量：加 $C\bar C=0$ 再用规则 12。例：$(A+B)(A+B+\bar C)=(A+B+C)(A+B+\bar C)(A+B+\bar C)$。

### 3.3 项的二进制表示（关键！）
- **标准积项 = 1 对应的行**：$AB\bar C\bar D=1010$（该行乘积为 1）。
- **标准和项 = 0 对应的行**：$A+B+\bar C+\bar D=0101$（该行和为 0）。
- 注意：积项中**变量为 0 → 写补**（如 A=0 写 Ā）；和项中**变量为 0 → 写原变量**。

### 3.4 表达式 ↔ 真值表
- **SOP → 真值表**：每个积项对应一行，输出置 1，其余置 0。
- **POS → 真值表**：每个和项对应一行，输出置 0，其余置 1。
- **真值表 → SOP**：取**输出为 1** 的行写积项（0→补、1→原）再相加。
- **真值表 → POS**：取**输出为 0** 的行写和项（0→原、1→补）再相乘。

> 例：真值表中 X=1 的行是 011、100、110、111（域 A,B,C）：
> SOP：$X=\bar A BC+A\bar B\bar C+AB\bar C+ABC$
> POS（X=0 的行 000、001、010、101）：$X=(A+B+C)(A+B+\bar C)(A+\bar B+C)(\bar A+B+\bar C)$

### 3.5 标准 SOP ↔ 标准 POS 转换
SOP → POS：找出 SOP **没有覆盖**的行（域内剩余行），写对应和项相乘。反向同理。
> 例：$X=\bar A BC+A\bar B\bar C+AB\bar C+ABC$ 覆盖 011,100,110,111 → 剩余行 000,001,010,101 → $X=(A+B+C)(A+B+\bar C)(A+\bar B+C)(\bar A+B+\bar C)$。

### 3.6 SOP vs POS 对比
| | SOP | POS |
|---|---|---|
| 项内运算 | AND | OR |
| 项间运算 | OR | AND |
| 识别条件 | 积项 = 1 | 和项 = 0 |
| 对应输出 | 1 | 0 |
| 取真值表哪些行 | 1 的行 | 0 的行 |

## 4. 卡诺图 Karnaugh Map（Lecture 10）⭐ 重点

### 4.1 基本概念
- 卡诺图 = 真值表的**阵列形式**，每格对应真值表一行；格数 = 2ⁿ。
- **格序按格雷码（Gray code）**：00 → 01 → 11 → 10（相邻格只变一个变量！）。
- **相邻性**：上下左右相邻；**最上行与最下行相邻、最左列与最右列相邻（wrap-around 环绕）**。

### 4.2 SOP 最小化（组 1）
**步骤 1 · 映射**：标准 SOP 的每个积项对应格填 1；非标准项**数值展开**（缺哪个变量，就把该项拆成该变量取 0 和取 1 的两格）。

**步骤 2 · 圈 1**：
- 每组只能含 **1、2、4、8、16…（2 的幂）个相邻格**；
- **越大越好**（积项越短）、**越少越好**（项越少）；每个 1 至少被圈一次，可重复圈。

**步骤 3 · 读积项**：
- 组内**取值有变化的变量消去**，保持不变的变量保留；
- 不变且为 **1** → 原变量；不变且为 **0** → 反变量。
- 3 变量图：4 格组 → 1 变量项；2 格组 → 2 变量项；1 格 → 3 变量项。

> 例（四角组）：4 变量图四角 (0000, 0010, 1000, 1010) 全是 1 → A、C 变，B=0、D=0 不变 → $F=\bar B\bar D$。

**Don't care（无关项 X）**：不可能出现的输入组合（如 BCD 的 1010–1111）。**X 可当 1 也可当 0**——只有当它能帮助组成更大组时才当 1 用；**所有 1 必须覆盖，X 不强制使用**。

> 例（BCD 检测）：Y = 1 于 0111、1000、1001；1010–1111 为 X。
> 不用 X：$Y=\bar A B C D + A\bar B\bar C\bar D + A\bar B\bar C D$（3 项）。
> 用 X：10、11 两行共 8 格（1 与 X）圈成一组 → 项 **A**（覆盖 1000、1001）；再把 0111 与 X 格 1111 圈成 2 格组 → 项 **BCD**。
> 最简结果：$Y=\mathbf{A + BCD}$。

### 4.3 POS 最小化（组 0）
- 标准 POS 的每个和项对应格填 **0**；
- 圈 **0**（规则同圈 1）；
- 读和项时**方向相反**：不变且为 **0** → 原变量；不变且为 **1** → 反变量。

> 例：0 位于 000,001,010,011,110（域 A,B,C）。
> 四个 0（000,001,010,011）组成 4 格组：A=0、B=0 不变 → 和项 **A+B**；剩余 110 单格 → 和项 **Ā+B̄+C**。
> 最小 POS：$X=\mathbf{(A+B)(\bar A+\bar B+C)}$。

### 4.4 卡诺图例题（3 变量 SOP）

真值表（域 A,B,C）：X=1 于 001, 010, 011, 110, 111。

```
        C
  AB    0   1
  00    0   1     ← 001
  01    1   1     ← 010, 011
  11    1   1     ← 110, 111
  10    0   0
```
圈组：① 四格组 010,011,110,111（行 01 与 11 相邻；B=1 不变，A、C 变）→ 项 **B**；② 单格 001（A=0→Ā，B=0→B̄，C=1→C）→ 项 **ĀB̄C**。
最小 SOP：$X=\mathbf{B+\bar A\bar B C}$。

> 技巧：先找**最大的组**（本题的 4 格组），再处理剩下的 1。注意 011、111 既在 ① 也在其它可能的 2 格组中——**能圈 4 格绝不圈 2 格**。

## 5. 组合逻辑功能电路（W11–12，讲义缺失，按 Floyd 补充）

> ⚠️ 这两讲（L11/L12）的课件不在 vault 中，以下按 Floyd《Digital Fundamentals》标准内容整理，请对照你的课件确认。

### 5.1 加法器 Adders
- **半加器 Half adder**：加两个位，输出**和 Σ = A⊕B** 与**进位 Cout = AB**。
- **全加器 Full adder**：加 A、B 与低位进位 Cin：
$$\Sigma = A\oplus B\oplus C_{in},\qquad C_{out}=AB+(A\oplus B)C_{in}$$
- **串行进位加法器 Ripple carry adder**：n 个全加器级联（进位逐个传递，慢）。
- 例：A=1101(13)+B=0111(7) 经 4 位加法器 → 10100(20)。

### 5.2 比较器 Comparators
- 1 位比较器：相等 $A\odot B$；A>B → $A\bar B$；A<B → $\bar A B$。
- 多位比较器：**从最高位开始**逐位比较，先出现不同的位决定大小。

### 5.3 译码器 Decoders（2ⁿ 选 1）
- n 输入 → 2ⁿ 输出；每个输出对应一个输入组合（**有效输出为唯一的 1**）。
- 例：2–4 译码器输出 $\bar A\bar B,\ \bar A B,\ A\bar B,\ AB$；3–8 译码器（74HC138 有使能端）。
- 应用：地址译码、七段显示译码器（BCD→七段）。

### 5.4 编码器 Encoders（译码器的逆）
- 2ⁿ 输入 → n 位编码输出；**一次只能一个输入有效**。
- 例：8 线–3 线编码器；十进制–BCD 编码器（键盘）。**优先级编码器**：多个输入同时有效时编码最大编号者。

### 5.5 多路复用器/多路分配器 MUX / DEMUX
- **多路复用器 MUX（数据选择器）**：2ⁿ 数据输入 + n 位选择线 → 1 输出，选中哪路数据输出哪路。
  - 例：4 选 1 MUX 输出 $Y=\bar S_1\bar S_0 D_0+\bar S_1 S_0 D_1+S_1\bar S_0 D_2+S_1 S_0 D_3$。
- **多路分配器 DEMUX**：1 数据输入 + n 位选择线 → 2ⁿ 输出，数据送到选中那一路（译码器 + 使能）。
